# v0.4 真机验收清单

> 无法自动化的部分全部集中在这里：需要 **1 台 Android 手机 + 1 台 Windows 电脑 + 同一局域网**。
> 每项都要实测勾选，全部通过后才有资格打 tag 发版。

## 0. 准备

- [ ] 电脑端：从 Release 下载 `SMS-Code-Bridge-Windows-vX.Y.Z.exe` 运行
- [ ] 手机端：安装 `SMS-Code-Bridge-Android-vX.Y.Z.apk`
- [ ] 两端确认在同一局域网（手机关闭移动数据测试）

## 1. 自动发现

- [ ] 手机端点击「自动寻找电脑」→ 数秒内提示「已找到 SMS Code Bridge：IP:端口」
- [ ] 电脑端未启动时点「自动寻找电脑」→ 提示未找到，不崩溃

## 2. 配对

- [ ] 电脑端控制台显示 6 位配对码（2 分钟有效）
- [ ] 手机端输入配对码 → 配对成功，出现「断开配对」按钮
- [ ] 输错配对码 → 电脑端拒绝并打印日志
- [ ] 配对码超时后使用 → 拒绝
- [ ] 同一配对码二次使用 → 拒绝（一次性）
- [ ] 重启电脑端后，已配对设备可自动恢复会话，无需重新配对

## 3. 核心闭环（最重要）

- [ ] 电脑收到验证码 → 剪贴板自动出现该验证码，全程无需手动操作
- [ ] 中文关键词短信（「验证码」「校验码」）能提取
- [ ] 英文关键词短信（code / OTP）能提取
- [ ] 验证码含空格或短横线（`123 456`、`123-456`）能提取
- [ ] 一条短信含多个数字时，提取的是验证码而非订单号等
- [ ] 普通短信（无关键词）不触发任何动作
- [ ] 全链路延迟主观无感（目标：粘贴时验证码已就位）

## 4. 静默与提示

- [ ] 关闭「转发时显示提示」→ 完全静默，仅剪贴板变化
- [ ] 打开提示 → 有轻量提示，可关闭

## 5. 历史记录

- [ ] 手机端历史列表与实际收到的验证码一致（仅时间 + 验证码）
- [ ] 清空历史 → 列表与存储都为空
- [ ] 历史超过容量上限 → 自动裁剪最旧的
- [ ] 历史中**绝无短信原文或手机号**

## 6. 断连与解绑

- [ ] 电脑端关闭后再打开 → 手机端心跳超时判定断连，重连后恢复
- [ ] 手机端「断开配对」→ 电脑端清除密钥与配对，旧会话消息被拒
- [ ] 解绑后未重新配对时，电脑端不接收任何验证码

## 7. 稳定性与兼容

- [ ] 收验证码期间，手机正常短信收发、其他 App 不受影响
- [ ] 电脑端托盘图标存在，菜单「显示配对码 / 退出」可用
- [ ] 托盘「退出」→ 程序干净退出，托盘图标消失
- [ ] 长时间（≥1 小时）挂机后功能仍正常（无内存/句柄泄漏迹象）

## 8. 安全自查

- [ ] 抓包（如 Wireshark）确认局域网内只能看到验证码消息，无短信原文、手机号
- [ ] 电脑端本地文件（设备密钥、历史）不含短信原文
- [ ] 伪造来源 / 错误 MAC 的 UDP 包 → 电脑端丢弃并记日志
